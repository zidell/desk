## 2026-10-31

### 새 기능 / 개선
- 첫 공개: macOS·Windows·Linux에서 보이는 화면을 읽고 실제 마우스·키보드로 앱과 웹을 다루는 desk 스킬
- Claude Code 플러그인, `npx skills`, git clone 세 가지 설치 방식 지원
- `desk install` 한 번으로 실행 명령과 Claude Code·Codex·Agents 스킬 연결을 준비. 다른 위치를 가리키던 이전 연결은 자동 교체, 링크가 아닌 파일·폴더는 보존
- Claude Code 플러그인 업데이트 뒤에도 실행 명령이 끊기지 않도록 고정 경로에 연결
- macOS `desk permissions`로 손쉬운 사용·화면 기록 권한 확인, `--request`로 시스템 승인 창 표시. 작업 시작 시 빠진 권한 경고
- `desk doctor`가 빠진 권한·구성 요소마다 고치는 방법을 함께 안내 (macOS 권한, Windows OCR 언어·관리자 권한, Linux 접근성 설정, 설치 연결 상태)
- 일주일에 한 번 이하로 새 버전을 확인해 작업 시작 시 설치 방식에 맞는 업데이트 방법 안내. 버전 번호만 확인하며 `DESK_UPDATE_CHECK=0`으로 끄기 가능
